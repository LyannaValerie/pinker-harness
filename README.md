# Pinker Harness

Harness específico da Pinker para execução de agentes na Forja Linux, com interface primária CLI/TUI interativa.

A Task preserva contrato, evidências e continuidade entre sessões, contas e provedores. A Forja mantém autoridade sobre ambiente, identidade de execução, lifecycle e isolamento; Trama, Book e Git mantêm suas responsabilidades próprias.

- [Autoridade de fundação — Issue #1](https://github.com/LyannaValerie/pinker-harness/issues/1)
- [Arquitetura proposta](docs/arquitetura.md): componentes, contratos, invariantes, continuidade e sequência H0. Ainda sujeita à decisão da Founder.
- [Probes existentes](probes/README.md): experimentos executáveis de autenticação e observabilidade.
- [Contrato P0 — Issue #2](https://github.com/LyannaValerie/pinker-harness/issues/2)

A arquitetura documentada descreve o sistema futuro. A implementação atual deve ser avaliada pelo código, pelos probes e pelas evidências das issues; sua existência não implica que o harness completo já esteja implementado.
